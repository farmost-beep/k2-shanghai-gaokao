1 科二代身份画像与决策前提

🧬 什么是"科二代"

父母一方或双方为中国科学技术大学（USTC）毕业生。USTC以物理、数学、计算机、化学等基础科学与工程学科见长，1958年建校，C9联盟成员，学风务实严谨。

科二代通常具备：理科基因、学术导向、务实风格、对"硬核"学科的价值认同。

📋 决策前提假设

选科物化双选（覆盖 98.5% 理工专业组）
地域限定上海本地大学（留沪偏好）
方向STEM优先：数学/物理/CS/EE/数据/AI
价值观重学科硬实力 > 学校虚名；重长期发展 > 短期热门
家庭资源USTC校友网络 + 上海本地信息优势
科二代决策原则：在孩子兴趣与能力范围内，优先选择与 USTC 学科基因相近的专业方向——基础扎实的理科、硬核的工科、前沿的交叉学科。不盲目追逐"热门"但学科底蕴薄的专业。

4 按位次分段的决策路径（核心）

以 2025 年上海市位次 为参考基准，给出各分段推荐策略。注意 2025 年考生 ~6.3 万，位次含金量较往年略有稀释。

🔍 快速定位：输入预估位次

🏆 位次 1-500：清北复交任意选

策略：综合评价批次主攻复交，零志愿冲清北。专业选择空间极大，应以兴趣和长期发展为唯一标准。

科二代推荐：

  • 复旦综评：数学英才班 / 自然科学试验班 / 微电子 / CS
  • 交大综评：IEEE试点班 / ACM班 / AI班 / 电子信息类
  • 零志愿：清华 / 北大（与科一代校友圈互补）

📌 此段位考生建议"兴趣导向"——选你真正想深耕的方向，而非"最热门"的方向。你已经有资格定义什么是好专业了。

🥇 位次 500-2000：复交普通批 + 综评双保险

策略：综评+普通批双线作战。综评保复交录取机会，普通批用于专业保底。此段位是竞争最激烈的区间。

科二代推荐：

策略院校专业组说明
综评冲复交综评（不限专业组）面试权重高，综合素质是关键
普通批稳复交物化组 → 同济AI/智能 → 华东师大统计按位次梯度排列
提前批复交医学院 / 同济有医学兴趣可考虑

📌 此段位最忌"综评孤注一掷"，建议普通批做好完整梯度。

🥈 位次 2000-5000：同济/华师大 + 上科大黄金区间

策略：复交普通批"冲一冲"（物化组个别专业组可能够到），主战场在同济、华东师大、上科大。

科二代推荐：

策略院校专业组说明
冲复交末位专业组 / 同济AI实验班位次边缘可尝试
稳同济智能科学·车辆工程 / 华东师大统计·CS·软件核心战场
稳上科大 CS / 电子信息 / 材料🌟科二代重点推荐
保华东理工化工 / 上大钱伟长学院确保不滑档

📌 此段位是科二代"最优性价比"区间——同济的硬核工科、华师大的统计CS、上科大的科研导向，均与USTC基因高度匹配。

🥉 位次 5000-10000：华东理工 / 上科大 / 上大

策略：上述三校为主战场，同济/华师大个别专业组可冲。

策略院校专业组说明
冲同济/华师大偏冷门专业组位次边缘
稳上科大物化组 / 华东理工化工·材料·制药核心战场
稳上大计算机·通信·数学性价比高
保东华材料 / 上大其他工科确保录取

📌 此段位上科大是最优解——科研导向、小班教学、导师制，与USTC本科教育理念最近似。

📌 位次 10000+：上大/东华 + 中外合作选项

策略：以上大、东华为基本盘，考虑中外合作办学项目获取额外资源。

策略院校专业组说明
稳上大工科 / 东华材料211保底
保上大中外合作 / 其他市属院校确保有学上

📌 此段位关注上大计算机学院的就业导向优势——上海本地IT企业对上大CS认可度高。

6 科二代决策 Checklist

从高三上学期到志愿提交，逐项打勾确认。

📅 高三上学期 · 准备期

  • 确认选科组合（物化双选 = 全覆盖理工专业组）
  • 了解各校强基计划/综合评价的报名条件与时间节点
  • 初步圈定目标院校范围（T1-T3 中 3-5 所）
  • 与科一代深度沟通：USTC校友圈内对各校的真实评价

📅 高三下学期（6月前）· 信息收集期

  • 关注上海教育考试院公众号，获取最新政策推送
  • 下载上一年《各专业录取人数及考分》，建立位次对标表
  • 参加目标院校的校园开放日 / 线上宣讲
  • 与孩子深入讨论兴趣方向：基础科学 vs 工程应用 vs 交叉学科

📅 6月9日-22日 · 出分前窗口

  • 熟悉志愿辅助填报系统（fzzytb.shmeea.edu.cn），模拟填报
  • 利用阳光志愿系统进行个性化筛选
  • 准备综评面试材料（如报名了综评）
  • 与孩子预估分数区间，制定 A/B/C 三套预案

📅 6月23日-7月1日 · 核心决策期（10天）

  • 出分后立即获取准确位次
  • 根据位次确定主攻院校档位（参考第4章分位次路径）
  • 核对选科与目标专业组的匹配关系（系统自动校验，但人工确认）
  • 排列志愿梯度：冲（1-2个）→ 稳（核心3-4个）→ 保（1-2个）
  • 参加 6月24-25日网上咨询，向招办确认关键问题
  • 科一代利用校友网络交叉验证关键信息
  • 确认"是否服从专业调剂"的每个志愿选择（不服从=退档风险）
  • 最终方案全家共识确认

📅 7月1-2日 · 正式提交

  • 在系统开放时间内提交（每天8:00-17:00）
  • 截图保存提交确认页面
  • 绝不等到最后1小时提交（系统拥堵风险）

⚠️ 科二代最易犯的5个错误

#错误正确做法
1过度自信，全部填"冲"，无保底必须设1-2个绝对安全的保底志愿
2只看分数不看位次，跨年直接比较位次是唯一可比锚点，分数每年波动
3认为"不服从调剂也没关系"不服从=进档后退档=直接滑入征求志愿
4综评孤注一掷，普通批不认真填综评不确定性高，普通批同样重要
5用"USTC当年我怎么报的"套用上海新高考院校专业组+平行志愿与30年前完全不同
