# 科二代 · 上海高考选校决策路径

> 父母为中国科学技术大学（USTC）毕业生 → 上海高考 → **上海本地大学 或 C9联盟** → STEM优先

## 范围

- **上海本地大学**：复旦、上交、同济、华东师大、上科大、华东理工、上大、东华
- **C9联盟大学**：清华、北大、复旦、上交、中科大、浙大、南大、哈工大、西交大

## 核心内容（8章）

1. **科二代身份画像** — 决策前提：物化双选、STEM优先、上海本地+C9双维度
2. **院校分层（T0-T4）** — 15校按STEM实力五档分层
3. **C9非上海院校详解** — 清北/中科大/浙大/南大/哈工大/西交大，逐校分析"出沪值不值"
4. **学科-院校匹配矩阵** — 9个学科方向×上海+C9双路径推荐
5. **分位次决策路径** — 5个位次区间，每段含上海选项+C9异地选项+交互式查询工具
6. **上海本地院校专业组详解** — 复/交/同/师/上科大逐一拆解
7. **决策Checklist** — 从高三上学期到提交的完整时间线+科二代特有易错点
8. **资源与工具**
