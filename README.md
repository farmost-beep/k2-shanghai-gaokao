# 科二代 · 上海高考选校决策路径

> 父母为中国科学技术大学（USTC）毕业生 → 上海高考 → 限定上海本地大学 → STEM优先

## 这是什么

一份专为"科二代"（USTC校友子女）设计的上海高考志愿填报决策框架。基于2025年上海高考制度与录取数据，聚焦上海本地大学的STEM专业选择。

## 核心内容（7章）

1. **科二代身份画像** — 决策前提与价值观
2. **上海高校STEM分层** — T1-T4四档8校详解
3. **学科-院校匹配矩阵** — 8个学科方向的院校推荐排序
4. **分位次决策路径** — 5个位次区间的冲/稳/保策略（含交互式查询）
5. **重点院校专业组详解** — 复交同师/上科大/华东理工逐一分析
6. **决策Checklist** — 从高三上学期到提交的完整时间线
7. **资源与工具** — 官方平台+科二代专属校友资源
